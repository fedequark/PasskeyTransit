# PasskeyTransit v0.7.1 English translation

This package contains the English translation of the PasskeyTransit v0.7.1
manuscript in Markdown, DOCX, and PDF formats.

The canonical replication package, raw evidence, deterministic derivations,
verification tools, and Spanish manuscript are archived at
https://doi.org/10.5281/zenodo.22925150.

The source repository and versioned release are available at:

- https://github.com/fedequark/PasskeyTransit
- https://github.com/fedequark/PasskeyTransit/releases/tag/v0.7.1
