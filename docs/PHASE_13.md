# Phase 13 publication package

The publication package contains the current Markdown manuscript, Word and PDF
renderings, results JSON, analysis manifest, five result tables, the external
interop result, the oracle capability report, literature review and submission
checklist.

The manuscript is written for an artifact-evaluation or security-measurement
venue. It reports exact designed-census numerators and denominators without sampling intervals, separates
synthetic controls from independent interoperability, and keeps all unexecuted
oracles local to the relevant claims.

The Word and PDF files must be regenerated after any manuscript change and
visually checked page by page. The final release manifest covers their hashes.
